These days I do both, with software quality and the build/deploy process as the parts I care about most.

That work is closed-source, so none of it shows up here — the repositories on this profile are personal projects, in a deliberately different corner of the ecosystem.

Certified in *Programming in C#* (70-483) and *Querying Microsoft SQL Server* (70-461); HBO Informatica, 2011.
